# Статья 5. Свобода предпринимательства
1. Республика Казахстан гарантирует право на свободу предпринимательской деятельности, свободное использование своего имущества для любой законной предпринимательской деятельности.
2. Субъекты предпринимательства вправе осуществлять любые виды предпринимательской деятельности, не запрещенные законами Республики Казахстан.
