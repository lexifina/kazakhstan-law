# Конституция Республики Казахстан

Конституция принята на республиканском референдуме 30 августа 1995 года. Прекратила действие с 01.07.2026 в соответствии с Конституцией РК, принятой на республиканском референдуме 15.03.2026.

Опубликование: Ведомости Парламента Республики Казахстан, 1996 г., N 4, ст. 217
